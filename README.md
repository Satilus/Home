# Home — особистий хаб

Особистий сайт: Home Assistant, календар, дашборд занять і списки фільмів, серіалів та аніме. Дизайн у стилі iOS.

## Що вже працює

**Списки** (`index.html`):
- постери, короткий зміст і рейтинг підтягуються автоматично;
- відмітка «переглянуто» переносить у «Переглянуто», повторне натискання повертає назад, є «Скасувати»;
- лічильник серій: після останньої серії назва сама переходить у «Переглянуто»;
- пошук і додавання нових назв;
- темна тема вмикається разом із системною.

Джерела даних (без ключів): TVmaze (серіали), AniList (аніме), Вікіпедія (фільми, описи українською).
Необов'язково: ключ TMDB у налаштуваннях (⚙️) дає постери для всього й описи українською.
Статуси поки зберігаються в браузері (localStorage).

## План

1. Списки на Firebase: вхід через Google, синхронізація між пристроями (Firestore).
2. Календар: синхронізація з Google Calendar (ZIT IB TimeTable + особисті).
3. Дашборд занять: статистика пар і академічних годин з 1 вересня.
4. Дім: Home Assistant через Cloudflare Tunnel.
