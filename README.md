# Тю і Шо

Особистий кінотеатр: списки фільмів, серіалів та аніме в стилі iOS 27 (Liquid Glass). Сайт: https://satilus.github.io/Home/

## Сторінки

**Головна** (`index.html`)
- заставка з фразою дня (раз за сесію, 16 оформлень у дусі різних фільмів);
- «Що подивитися сьогодні?» — три питання й порада з твого списку;
- «Нові серії», «Продовжити перегляд», «Ідея на вечір», новинки;
- «Мій рік у кіно» з листівкою;
- налаштування (⚙): ключ TMDB.

**Кінотеатр** (`kino.html`)
- постери, опис, рейтинг, кадри, актори, трейлер, схожі, «Де дивитися в Україні»;
- статуси «Дивлюся / Планую / Переглянуто», свайпи, контекстне меню, «Скасувати»;
- мій рейтинг у перчиках (5-й — вогник 🔥), нотатки, дата перегляду;
- пошук, сортування, жанри, фільтр тривалості.

**Дані** (кнопка-хмаринка): резервна копія у файл, відновлення, синхронізація між пристроями через приватний GitHub Gist.

Джерела даних: TVmaze, AniList, Вікіпедія, Вікідані; необов'язково — TMDB (ключ вводиться в налаштуваннях і зберігається лише в браузері). Російський контент відфільтровується.

## Публікація

GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
