# Правила проєкту «Тю і Шо глянемо»

Назва сайту: **Тю і Шо глянемо** (репозиторій Satilus/Home).

- **Жодних російських фільмів, серіалів чи аніме-адаптацій російського виробництва.** Не додавати їх у стартові дані, відфільтровувати в пошуку й під час підтягування метаданих (TMDB: `origin_country`/`original_language` = RU/ru; TVmaze: мова Russian або країна RU; Вікіпедія: опис містить «Russian»).
- Інтерфейс українською, дизайн у стилі iOS (світла й темна тема).
- Ніяких ключів чи паролів у коді: ключі API вводяться користувачем і зберігаються лише в його браузері.

## Перевірка (обов'язково при кожному додаванні)
- Кожну нову назву фільму/серіалу/аніме перевіряти: офіційна українська назва (не калька з російської), оригінальна назва, рік, тип; країна виробництва — не росія.
- Для серіалів і аніме фіксувати перевірений ідентифікатор TVmaze у `PIN.tvm` (kino.html), для фільмів — назву статті англійської Вікіпедії в `PIN.wt`. Західну анімацію (не з Японії/Китаю) позначати в `PIN.tvmOnly`.
- **Зображення — обов'язково при кожному додаванні.** Додав фільм/серіал/аніме — переконатися, що постер знаходиться (закріплений `PIN.tvm`/`PIN.wt`/AniList); якщо ні — знайти й закріпити джерело. Не покладатися лише на автопідбір.
- Не вигадувати дані: якщо щось не вдалося підтвердити — прямо сказати користувачу.

## Структура
- `index.html` — **Головна**: заставка з мотиваційною фразою (раз за сесію, `sessionStorage`), 16 тем оформлення в `THEMES` (шрифт Google Fonts із кирилицею, ефект фону, тип появи), «Продовжити перегляд», «Ідея на вечір», новинки (TVmaze-прем'єри без ключа; TMDB з ключем), фільтр російського.
- `phrases.js` — власні мотиваційні фрази (не цитати з фільмів); показуються по колу без повторів. Додаючи нові, перевіряти, що не дублюються.
- `kino.html` — **Кінотеатр** (фільми, серіали, аніме). `kino.html#open=<id>` відкриває картку. Пошук, сортування, жанри (`GENRE_MAP` нормалізує жанри з усіх джерел українською), фільтр тривалості; свайпи (вліво — переглянуто, вправо — дивлюся), довге натискання — контекстне меню; картка на весь екран: фон із постера, трейлер, схожі, «Де дивитися» (TMDB, регіон UA). Кеш `lists.more` (трейлер/схожі/провайдери).
- Головна також має майстер «Що подивитися сьогодні?», «Нові серії» (TVmaze nextepisode), «Мій рік у кіно» з листівкою (canvas), нагадування про резервну копію (shared.js).
- `shared.js` — спільне для всіх сторінок: кнопка «Дані» (резервна копія JSON, відновлення, синхронізація через приватний GitHub Gist з токеном користувача), реєстрація PWA. Підключати в `<head>` кожної нової сторінки разом із `manifest.webmanifest`. Нові ключі localStorage називати з префіксом `lists.` (або додати префікс у `PREFIXES`), кеші — у `SKIP`.
- `glass.css` + `motion.js` — стиль iOS 27 (Liquid Glass) і рух для всіх сторінок: великий заголовок → скляна панель, «крапля» в перемикачах, поява каскадом, пружинні аркуші, переходи між сторінками. Підключати на кожній сторінці; при зміні — піднімати `?v=` у посиланнях.
- `sw.js` — офлайн-кеш; при додаванні сторінки внести її в `SHELL` і підняти версію `V`.
- Нижня панель вкладок однакова на всіх сторінках (Головна, Кінотеатр) — нову сторінку додавати в усі.
- Налаштування (ключ TMDB, сповіщення) — кнопка ⚙ на Головній.
- Колекції (kino.html): франшиза (`meta.col`: TMDB collection або Вікідані P179) і режисер (`meta.dir`: TMDB credits або P57); повний склад — TMDB або SPARQL Вікіданих з фільтром країни Q159 (росія); кеш `lists.cols`.
- Сітка сезонів: епізоди з TVmaze (`lists.epcache`), переглянуті серії — `item.seen` (ключі «сезон.серія»), `item.ep`/`item.total` синхронізуються автоматично.
- Сповіщення: `TyuPush` у shared.js (VAPID-ключі генеруються в браузері, зберігаються в `lists.push` → Gist), обробники push у sw.js, розсилка — `.github/workflows/new-episodes.yml` + `.github/scripts/notify.mjs` щогодини; потрібен секрет репозиторію `GIST_TOKEN`. Стан розсилки — файл `push-state.json` у тому ж Gist.
- Нумізматику й Фотоапарати видалено з проєкту за рішенням користувача (22.11.2026).
