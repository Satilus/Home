# Правила проєкту «Тю і Шо»

Назва сайту: **Тю і Шо** (репозиторій Satilus/Home).

- **Жодних російських фільмів, серіалів чи аніме-адаптацій російського виробництва.** Не додавати їх у стартові дані, відфільтровувати в пошуку й під час підтягування метаданих (TMDB: `origin_country`/`original_language` = RU/ru; TVmaze: мова Russian або країна RU; Вікіпедія: опис містить «Russian»).
- Інтерфейс українською, дизайн у стилі iOS (світла й темна тема).
- Ніяких ключів чи паролів у коді: ключі API вводяться користувачем і зберігаються лише в його браузері.

## Структура
- `index.html` — **Кінотеатр** (фільми, серіали, аніме).
- `coins.html` — **Нумізматика** (колекція монет і список бажаного). Стартові монети — масив `SEED` у `coins.html`; для кожної заповнювати тираж, метал, масу, діаметр, серію, коротку історію (своїми словами) та посилання на зображення з першоджерела (НБУ / Wikimedia Commons), із зазначенням джерела в `imgSource`.
- Нижня панель вкладок однакова на всіх сторінках — нову сторінку додавати в обидві.
