# Правила проєкту «Тю і Шо»

Назва сайту: **Тю і Шо** (репозиторій Satilus/Home).

- **Жодних російських фільмів, серіалів чи аніме-адаптацій російського виробництва.** Не додавати їх у стартові дані, відфільтровувати в пошуку й під час підтягування метаданих (TMDB: `origin_country`/`original_language` = RU/ru; TVmaze: мова Russian або країна RU; Вікіпедія: опис містить «Russian»).
- Інтерфейс українською, дизайн у стилі iOS (світла й темна тема).
- Ніяких ключів чи паролів у коді: ключі API вводяться користувачем і зберігаються лише в його браузері.

## Перевірка (обов'язково при кожному додаванні)
- Кожну нову назву фільму/серіалу/аніме перевіряти: офіційна українська назва (не калька з російської), оригінальна назва, рік, тип; країна виробництва — не росія.
- Для серіалів і аніме фіксувати перевірений ідентифікатор TVmaze у `PIN.tvm` (index.html), для фільмів — назву статті англійської Вікіпедії в `PIN.wt`. Західну анімацію (не з Японії/Китаю) позначати в `PIN.tvmOnly`.
- Для монет перевіряти рік, дату введення, тираж, масу, діаметр за НБУ/Вікіпедією; для зображень задавати `fileBase` (назва файлу «<назва> аверс/реверс») і `wiki` (стаття «… (монета)»).
- Для фотоапаратів перевіряти роки випуску, виробника, байонет і штатний об'єктив; у полі `q` — англійська назва моделі для пошуку фото.
- **Зображення — обов'язково при кожному додаванні.** Будь-що додав (фільм, монету, фотоапарат) — одразу знайти, як воно виглядає, і закріпити перевірене фото прямо в даних (`img` + `imgSource` з назвою файлу; для Commons — посилання `Special:FilePath/<файл>`). Не покладатися лише на автопідбір.
- Не вигадувати дані: якщо щось не вдалося підтвердити — прямо сказати користувачу.

## Структура
- `index.html` — **Кінотеатр** (фільми, серіали, аніме).
- `coins.html` — **Нумізматика** (колекція монет і список бажаного). Стартові монети — масив `SEED` у `coins.html`; для кожної заповнювати тираж, метал, масу, діаметр, серію, коротку історію (своїми словами) та посилання на зображення з першоджерела (НБУ / Wikimedia Commons), із зазначенням джерела в `imgSource`.
- `cameras.html` — **Фотоапарати** (колекція фотоапаратів і список бажаного). Стартові апарати — масив `SEED` у `cameras.html` (бренд, модель, рік, тип, формат, байонет, об'єктив, коротка історія своїми словами).
- `shared.js` — спільне для всіх сторінок: кнопка «Дані» (резервна копія JSON, відновлення, синхронізація через приватний GitHub Gist з токеном користувача), реєстрація PWA. Підключати в `<head>` кожної нової сторінки разом із `manifest.webmanifest`. Нові ключі localStorage називати з префіксом `lists.`/`coins.`/`cams.` (або додати префікс у `PREFIXES`), кеші — у `SKIP`.
- `sw.js` — офлайн-кеш; при додаванні сторінки внести її в `SHELL` і підняти версію `V`.
- Нижня панель вкладок однакова на всіх сторінках — нову сторінку додавати в усі.
